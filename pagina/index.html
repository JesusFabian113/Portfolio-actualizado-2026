Domínio Técnico & Aplicação Prática

Engenharia Backend & APIs

Desenvolvimento, especificação e teste de endpoints de APIs RESTful para consumo seguro utilizando Swagger / OpenAPI. Aplicação sólida de Programação Orientada a Objetos (POO).

Frontend Web & UI/UX

Estruturação e estilização de páginas web modernas e responsivas utilizando HTML5, CSS3 e JavaScript. Mapeamento de fluxos, arquitetura de informação e wireframes no Figma, Balsamiq, Canva, Genially e Notion.

Bancos de Dados Relacionais

Experiência prática com PostgreSQL, SQLite e Microsoft SQL Server Management Studio (SSMS). Criação de esquemas, consultas SQL (DDL e DML), normalização e relacionamentos entre tabelas.

Qualidade de Software (QA)

Técnicas de Qualidade e Testes de Software para validação de regras de negócio, testes funcionais e auditoria de requisitos. Verificação e validação de APIs antes e após o deploy.

Ambientes & Ferramentas

Inteligência Artificial & Modelagem
